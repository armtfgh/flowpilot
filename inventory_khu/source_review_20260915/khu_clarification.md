# KHU clarification supplied by the user on 2026-09-15

This is a transcription of the four answers in the user's email excerpt, not a fetched email.

1. Reactor and module compatibility: We have added a remarks column to the "Reactor (tubing)" sheet in the revised inventory indicating UV-150 compatibility for each coil, so that information is now included directly in the inventory itself.

2. Combining pump types: Using different pumps within a single process is possible. However, this combination is not preferred unless a syringe pump is specifically required, for example when handling a reagent that the R-series or E-series pumps cannot accommodate.

3. UV-150 platform requirement: To use the UV-150 module, the Vapourtec R-series or E-series system must be used. That said, when it comes to pump selection, an external syringe pump can also be used if a reagent cannot be handled by the peristaltic or HPLC pump built into the R-series or E-series system.

4. Minimum flow settings: The "minimum flow rate" refers to the lowest flow rate the equipment supports, while the "minimum operating/adjustment flow" does indeed refer to the setting increment.

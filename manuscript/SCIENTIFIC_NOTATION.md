# Publication notation convention

Apply this convention to future manuscript and ESI edits.

- Use real Word subscripts/superscripts or structured equations, not underscores
  or manually reduced text sizes, for scientific notation.
- Italicize quantity symbols. Keep descriptive subscripts (liq, gas, STP, abs,
  inlet, wall) and units upright. Preserve italic variable indices in equations.
- Use Q with subscript liq for liquid volumetric flow; Q with subscript gas,STP
  for inlet-reference gas flow; V with subscript R for reactor volume; V with
  subscript liq for liquid holdup volume. Never exchange those volume meanings.
- Use Greek tau for time symbols. Tau with subscript inlet denotes the nominal
  inlet/STP index, not actual operating liquid residence time. State the basis.
- Apply chemical-formula subscripts, isotope superscripts and unit exponents.
  Do not change concentrations, numerical conditions or recorded outcomes.
- Preserve literal software identifiers, filenames, paths, URLs and JSON keys.
  Do not convert Q_gas_sccm when it names the actual software field.
- Raw prompts, response logs and the full verbatim council companion remain
  untouched. Any typeset reproduction must disclose typography normalization.
- Preserve existing document fonts, headings, numbering, layout and artwork.
  Embedded image labels require a separate source-figure revision; do not
  silently replace figures while typesetting editable document text.

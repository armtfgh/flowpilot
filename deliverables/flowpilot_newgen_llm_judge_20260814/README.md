# Withdrawn Score Benchmark

The score-based benchmark previously published at this location was withdrawn after retrospective validity checks found architecture leakage, unequal evidence packets, an assurance extraction bug, order-dependent pairwise results, low judge agreement, same-family bias, and unstable seed bookkeeping.

No score, ranking, or winner figure from that campaign should be used.

The immutable raw campaign remains at:

`ablation_results/newgen_benchmark/newgen_llm_judge_v1_20260814`

The withdrawn aggregate package is retained only for audit at:

`deliverables/withdrawn/flowpilot_newgen_llm_judge_20260814_invalid`

The replacement analysis is a holistic error audit with fixed criteria and actionable model-fix tickets. It does not calculate a composite quality score.
